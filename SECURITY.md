# Security Policy

## Reporting a vulnerability

Please report potential security issues privately to the repository owner. Do not publish sensitive details in a public issue before the issue has been reviewed.

## Keeping the repository safe

- Never commit API keys, passwords, access tokens, or private certificates.
- Store local secrets in environment variables or an ignored configuration file.
- Rotate any credential that is accidentally exposed.
- Keep dependencies and project tooling up to date.

## Scope

This policy applies to the source code, configuration, documentation, and deployment assets in this repository.
