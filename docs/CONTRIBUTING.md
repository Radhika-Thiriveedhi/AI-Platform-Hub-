# Contributing Guide

## Before you start

- Check the existing project documentation and open work.
- Keep each change focused on one purpose.
- Use a descriptive branch name and commit message.

## Pull requests

1. Create a branch from `main`.
2. Make and verify the change.
3. Open a pull request with a short summary.
4. Address review feedback if needed.
5. Merge only when the change is ready.

## Documentation

Update relevant documentation whenever a change affects project setup, behavior, or user-facing workflows.
